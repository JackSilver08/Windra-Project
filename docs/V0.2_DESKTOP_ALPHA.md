# Windra 0.2 Desktop Alpha

## Definition of Done

Windra 0.2 được xem là đạt mốc alpha khi:

- Shell hiện desktop theo mockup chính thức.
- Intro motion chạy mượt và không chặn thao tác.
- Launcher mở/đóng được và launch app.
- Dock mở được Files, Calc, Notes, Browser và Settings.
- Quick Settings và Power Menu có tương tác alpha.
- Power Menu an toàn trong preview.
- Files duyệt được filesystem thật nhưng chưa partition.
- Notes mở/lưu file text.
- Calc tính toán cơ bản.
- Go services từ Foundation vẫn test/build được.

## Motion budget

- Micro interaction: 90–120 ms.
- Panel: khoảng 190 ms.
- Desktop element: 190–280 ms.
- Icon stagger: 42 ms.
- Tổng intro mục tiêu: < 600 ms.

## Performance budget

- `windra-shell` preview mục tiêu: < 200 MB RAM.
- Full Windra desktop idle mục tiêu dài hạn: 450–650 MB.
- Không dùng blur nặng trong desktop mặc định.
- Motion chủ yếu dùng opacity/translate/scale.
